# OpenWeibo

一个本地优先的第三方微博 Android 客户端。关注时间线严格按发布时间排序，没有算法推荐；界面参考 OpenCode Windows 风格的细边框面板，支持深色、浅色与跟随系统。

> 非官方项目，与新浪微博没有关联。仅用于个人学习与自用。

## 功能

- **微博账号登录**：在应用内打开微博官方 WebView 登录页，支持短信/扫码/密码等官方登录方式。应用不接触账号密码。
- **关注时间线**：读取关注信息流，按微博发布时间倒序合并展示；支持下拉刷新、滚动加载更多、回到顶部。
- **评论与转发**：点击微博正文或卡片底部的「评」「转」进入详情，查看评论或转发列表；在评论区和转发区之间可直接左右滑动切换。支持刷新与分页加载，可直接发表评论，也可带转发语或直接转发。
- **原生发布微博**：时间线右上角的编辑按钮进入原生发布页，支持文字、最多 9 张原图/GIF，或 1 个原始视频文件；可选公开、关注可见、好友可见、仅自己。图片与 GIF 按原始字节上传，不压缩；视频按原始文件分片上传，由微博云端转码，本地不做二次压缩。
- **编辑与删除微博**：自己发布的微博卡片右上角显示「⋯」管理入口，可编辑正文或删除微博。编辑保留原有图片/GIF，保存后所有已打开的时间线、主页、搜索结果和详情页同步更新；删除需二次确认，成功后立即从列表移除。
- **应用内视频播放**：视频封面在客户端内直接打开全屏播放器，支持清晰度选择与多清晰度自动回退、播放/暂停、拖动进度、静音和错误重试，不跳转系统浏览器或网页；可将 MP4 清晰度下载到系统相册。
- **长微博全文**：点击长微博的「展开全文」会按需请求微博全文接口，完整显示正文；转发原文中的长文也支持展开与收起。
- **GIF 动图**：自动识别微博图片中的 GIF，在时间线、搜索结果、详情页和全屏查看器中直接播放动图。
- **转发原文与用户主页**：转发卡片可点击进入原微博；点击任意微博、评论或转发列表中的头像/昵称，进入原生用户主页并分页浏览其微博；在他人主页可直接关注或取消关注。
- **互相关注识别**：在他人主页读取微博返回的关注关系；如果对方也关注你，关注按钮会显示「互相关注」，否则保持「已关注」。
- **实时热搜**：支持热搜、文娱、社会、科技、体育、生活、游戏七个分类，可下拉刷新；点击热搜条目进入原生搜索结果页，使用客户端微博卡片展示，不再打开微博移动端网页。
- **关注与粉丝**：「我的」→「我的关注」/「我的粉丝」，或直接点击个人面板中的关注、粉丝数字，可查看自己关注的人和关注自己的账号；关注数始终显示当前数量，点击数字即可进入「我的关注」；支持刷新、分页加载，点击用户可进入其原生主页。
- **我的主页入口**：在「我的」页面点击头像、昵称或「微博」数字，直接进入自己的原生微博主页，可分页浏览自己发布的微博并继续查看评论、图片和视频。
- **双击刷新时间线**：在底部导航栏快速双击「时间线」按钮，立即刷新关注信息流。
- **原图查看与保存**：点击配图进入全屏查看器，左右滑动浏览；再次单击图片即可关闭并回到正文；右上角保存当前原图。
- **一键保存全部原图**：每条微博底部的「保存原图 · N」会保存正文与转发微博中的全部图片，自动去重。
- **视频下载**：播放器右上角的下载按钮可选择 MP4 清晰度保存到系统相册的 `Movies/OpenWeibo`，下载过程显示进度。
- **深色模式**：在「我的」→「深色模式」中可选择跟随系统、开启或关闭；切换后整个应用立即生效，并保存在本机，重启后仍然有效。
- **本地会话加密**：微博 Cookie 使用 Android Keystore 的 AES-GCM 加密后保存在本机 SharedPreferences；不备份、不上传。
- **OpenCode Windows 风格 UI**：Geist / Geist Mono 字体、深色/浅色双调色板、细边框面板、克制的绿色状态点与琥珀色高亮。界面刷新率跟随设备与系统调度，不再请求固定显示模式。
- **快速滑动优化**：列表图片使用轻量 `AsyncImage` 路径，移除列表内加载旋转动画、淡入动画和逐卡片尺寸动画；快速上下滑动时减少主线程合成与动画负担。

## 安装

1. 将 `OpenWeibo-0.9.1-debug.apk` 传到 Android 手机。
2. 允许文件管理器/浏览器「安装未知来源应用」。
3. 安装并打开 OpenWeibo。
4. 在登录页完成微博登录，应用检测到有效会话后自动进入时间线。

- 最低系统：Android 8.0（API 26）
- 目标系统：Android 15（API 35）
- APK 为 **debug 签名**，适合个人安装测试；如需公开分发，请配置自己的 release 签名。

APK 下载：GitHub Releases 附件 `OpenWeibo-0.9.1-debug.apk`

## 使用说明

### 登录

登录页加载的是微博官方页面 `passport.weibo.com`。登录成功后，页面会跳回 `m.weibo.cn`，应用读取该域名下的 Cookie 并调用 `/api/config` 校验会话；同时读取 `weibo.com` 域名下的 Cookie，供视频上传使用。

- 若自动检测没有触发，可点击底部「我已登录，继续」。
- 若微博要求验证码或二次验证，请直接在 WebView 中完成。
- 退出登录会清除本机保存的加密会话，不会影响微博账号本身。

### 时间线

- 只有关注账号的微博会进入时间线；应用在本地再按 `created_at` 倒序排序并去重。
- 向下滚动接近底部时自动加载下一页。
- 顶栏刷新按钮、下拉刷新，以及双击底部「时间线」按钮都会重新请求第一页。
- 点击微博正文、作者区域或卡片空白处即可进入评论区；点击配图仍进入大图查看器，「展开全文」会按需加载长微博完整正文。
- 点击头像或昵称进入该用户的原生主页，不影响当前时间线位置。
- 博主转发的内容会在卡片内显示原文摘要，点击原文面板、正文或「原文 ↗」可进入原微博详情；若原文是长微博，也可以在卡片内展开全文。

### 发布微博

- 入口：时间线右上角的编辑按钮。发布页支持正文、图片/GIF、视频与可见范围设置。
- 图片与 GIF 通过系统文件选择器读取原始文件，逐张上传到微博图床，不压缩、不转码；GIF 保留 `image/gif` 类型与动画。单张上限 10MB，最多 9 张。
- 视频通过系统文件选择器选择一个原始文件，按微博网页版的分片协议上传；本地不压缩、不转码，上传后由微博云端转码。单个视频上限 4GB。
- 视频与图片不能混发；选择新视频会替换当前视频。视频发布前会尝试从首帧生成封面，失败时仍会继续发布。
- 可见范围：公开、关注可见、好友可见、仅自己。发布成功后会自动关闭发布页并刷新时间线。
- 图片上传依赖 `m.weibo.cn` 会话，视频上传还需要 `weibo.com` 的网页版 Cookie。登录时应用会一并读取网页版 Cookie；若视频发布提示需要网页版会话，请退出后重新登录一次。
- 发布属于微博写操作，可能受到账号权限、微博风控与频率限制（`code: 100000` / `100001`）影响；失败时会保留正文与已选媒体，可直接重试。

### 编辑与删除微博

- 入口：自己发布的微博卡片右上角「⋯」。只有当前登录账号发布的微博会显示该入口；他人的微博不显示管理按钮。
- 编辑正文：点击「编辑正文」后，应用先通过 `statuses/show` 读取 `can_edit`、`raw_text` 与 `pic_ids`，确认微博仍允许编辑后再打开编辑页。
- 编辑页只允许修改正文。原有图片/GIF 会通过 `picId` 原样传回，不会被重新压缩、替换或删除；可见范围、发布时间与互动数据保持不变。保存成功后微博服务端会显示「已编辑」标记。
- 含视频的微博和转发微博暂不支持编辑；正文超过 2000 字、微博返回 `can_edit=false`、或已超过微博允许的编辑时限时，会提示无法编辑。
- 删除微博：点击「删除微博」后需要二次确认；删除成功后这条微博会立即从时间线、用户主页、搜索结果及详情页中移除，评论和转发也会一并消失，无法恢复。
- 编辑与删除均为微博写操作，可能受到账号权限、微博风控与频率限制影响。删除失败时会关闭确认框并提示错误，可重新打开管理菜单重试。

### 视频与动图

- 点击视频封面进入应用内全屏播放器，默认播放微博返回的最高清晰度；点击右上角或底部的分辨率按钮，可在播放中切换其他清晰度，切换时会保留当前播放进度。
- 某个清晰度不可用时会自动回退到下一档；全部失败时显示错误提示，可点击「重新加载」重试。
- 播放器支持播放/暂停、拖动进度条、静音、重试，并显示当前播放时间。
- 点击右上角下载按钮，可选择可下载的 MP4 清晰度保存到 `Movies/OpenWeibo`；下载过程会显示百分比，完成后直接出现在系统相册/文件管理器中。
- HLS（`.m3u8`）清晰度暂不支持离线保存；若微博同时返回 MP4 清晰度，可在下载面板中选择对应档位。
- 视频地址由微博 CDN 提供且通常带有效期；若长时间停留后播放失败，刷新时间线重新获取即可。
- GIF 动图会在微博卡片中自动播放，点击进入大图查看器后继续播放；Android 8 使用 GifDecoder，Android 9 及以上使用系统 ImageDecoder。

### 用户主页

- 在微博卡片、评论区或转发列表中点击头像/昵称，进入原生用户主页。
- 在「我的」页面点击自己的头像、昵称或「微博」数字，也可以直接进入自己的主页；自己的主页不显示关注按钮。
- 主页展示头像、认证信息、简介、粉丝/微博/关注数量，以及该用户的微博流。
- 在他人主页底部可直接关注或取消关注；按钮会显示当前关注状态与请求进度，成功后粉丝数会同步更新。自己的主页不显示关注按钮。
- 如果对方也关注你，按钮文字会显示「互相关注」；取消关注后恢复为「关注」，重新关注时按微博返回的关系恢复显示。
- 用户主页微博支持下拉刷新、自动分页、查看评论/转发、播放视频、保存原图，并可继续进入转发原文或其他用户主页。
- 返回键或左上角返回会回到进入主页前的位置。

### 评论与转发

- 点击微博正文、卡片空白处或底部「评 N」进入详情页并定位到评论列表；点击「转 N」定位到转发列表。
- 进入详情页后，可在内容区域左右滑动切换「评论」和「转发」两个分区，也可以点击顶部分类按钮切换。
- 评论与转发列表都会在滚动到底部时自动加载下一页，也可在顶栏手动刷新。
- 评论输入框位于详情页底部，最多 140 字；发送成功后新评论会出现在列表顶部。
- 转发页底部与顶栏都有「转发」入口；可输入转发语，也可留空直接转发。
- 评论、转发与关注均为微博官方接口的写操作，可能受到账号权限、博主设置或频率限制影响。

### 关注与粉丝

- 入口：「我的」→「我的关注」/「我的粉丝」，或直接点击个人面板中的关注、粉丝数字。
- 个人面板中的关注数始终显示当前数量，不再显示「查看」；点击关注数字直接进入「我的关注」。
- 进入「我的」页面时会静默刷新一次账号关注/粉丝计数，旧会话也会自动补齐。
- 关注列表展示当前账号关注的人，粉丝列表展示关注当前账号的人；两者都支持手动刷新与分页加载。
- 点击列表中的用户可进入其原生微博主页，并可继续查看微博、图片、视频或再次进入其关注/粉丝关系。
- 关注/粉丝接口会遵守账号与博主的隐私设置，部分关系可能无法查看。

### 流畅度

- 时间线、搜索结果、用户主页、评论和转发列表共用轻量图片路径，快速上下滑动时不再为每张图片创建子组合。
- 列表图片加载中只显示静态占位色，不再在卡片内运行无限旋转进度动画；全屏大图仍保留加载提示。
- 移除了微博卡片根布局的 `animateContentSize`，展开/收起长文时以内容直接更新为主，避免滚动中叠加尺寸动画。
- 列表项使用稳定 key 与 `contentType`；加载更多时的排序和去重已移到后台线程。

### 外观与主题

- 入口：「我的」→「SYSTEM」→「深色模式」。
- 可选项为「跟随系统」「开启」「关闭」；点击后立即切换整个应用的背景、面板、文字、边框与强调色，无需重启。
- 「跟随系统」会随 Android 系统深色模式开关自动切换；状态栏与导航栏图标也会同步适配深色或浅色背景。
- 选择结果保存在本机，重新打开应用后仍然有效；退出登录不会清除主题设置。

### 长微博全文

- 时间线、搜索结果、用户主页和详情页中的长微博，在正文下方会显示「展开全文」。
- 首次点击会从微博 `/statuses/extend` 接口获取完整正文；加载中显示进度，失败时显示「重试全文」并给出错误提示。
- 获取成功后可以正常「收起」；再次展开不会重复请求。
- 转发卡片中的长文同样支持展开全文。

### 热搜

- 默认显示「热搜」分类，可横向切换其他分类。
- 热搜条目点击后进入原生搜索结果页：顶部显示热搜词，下面使用客户端微博卡片展示相关正文，不再加载微博移动端网页。
- 搜索结果支持下拉刷新、自动分页、点击正文进入评论区、查看图片和保存原图。
- 左上角返回热搜列表；从搜索结果进入微博详情后，返回会先回到搜索结果。

### 保存原图

- 点击图片进入全屏查看器，右上角下载按钮保存当前图片。
- 在全屏查看器中再次单击图片会关闭查看器并返回正文；左右滑动可浏览同一组图片。
- 微博卡片底部「保存原图 · N」保存全部配图。
- Android 10 及以上写入系统相册的 `Pictures/OpenWeibo`，无需存储权限。
- Android 8/9 首次保存时会申请存储权限。
- 视频下载写入 `Movies/OpenWeibo`；HLS 流不提供离线下载。

## 构建

环境要求：

- JDK 17
- Android SDK Platform 35、Build-Tools 35.0.0
- Gradle 8.9（项目包含 wrapper）

```powershell
cd OpenWeibo
$env:JAVA_HOME = 'C:\path\to\jdk17'
$env:ANDROID_HOME = 'C:\Users\<user>\Android\Sdk'
.\gradlew.bat assembleDebug
```

产物：`app/build/outputs/apk/debug/app-debug.apk`

若路径包含中文，项目已在 `gradle.properties` 中开启 `android.overridePathCheck=true`。

## 技术实现

- Kotlin 2.0.21 + Jetpack Compose（Material 3）+ AGP 8.7.3
- 网络：OkHttp 4.12、kotlinx.serialization
- 图片：Coil 2.7 + `coil-gif`（GIF 动图解码）
- 视频：Media3 ExoPlayer 1.5.1 + HLS，自定义 Compose 控制层
- HTML 文本清洗：Jsoup
- 架构：单 Activity + Compose，`AppContainer` 手动依赖注入；`FeedViewModel` / `ComposeViewModel` / `HotSearchViewModel` / `SearchViewModel` / `PostDetailViewModel` / `FollowersViewModel` / `ProfileViewModel` 管理分页、上传与状态
- 长微博全文通过 `CompositionLocal` 提供按需加载器，卡片只在点击「展开全文」时请求全文，并在当前 Composable 内保留已加载内容
- 图片保存与视频下载分别由 `ImageSaver` / `VideoSaver` 写入 MediaStore；Android 8/9 使用公共目录与存储权限
- `SettingsStore` 持久化主题模式，`OpenWeiboRoot` 在深色/浅色调色板之间切换，并同步状态栏与导航栏图标颜色
- 关注关系由 `WeiboUser.following` 与 `followsMe` 组合为 `isMutual`，主页关注按钮据此显示「互相关注」或「已关注」
- 列表图片改用 `AsyncImage`，避免每张图片/头像的 `SubcomposeAsyncImage` 子组合开销；图片加载不再启用全局 crossfade
- `LazyColumn` 为微博、评论、转发、页脚等不同结构设置 `contentType`，减少滚动时跨类型复用造成的额外重组
- 时间线的合并、去重与按发布时间排序移到 `Dispatchers.Default`，避免加载更多时在主线程做列表排序
- 详情页使用 `HorizontalPager` 在评论与转发之间左右滑动切换
- 覆盖层使用原生导航栈，支持详情、主页、搜索、粉丝、关注、发布与编辑之间连续跳转并逐层返回
- `AppContainer.postChanges` 以共享事件流广播编辑/删除结果；时间线、用户主页和搜索结果 ViewModel 收到后直接更新本地列表，无需整页刷新

主要接口：

- 会话校验与写操作令牌：`https://m.weibo.cn/api/config`（读取 `data.st`）
- 关注时间线：`https://m.weibo.cn/feed/friends`（`max_id` / `next_cursor` 分页）
- 评论列表：`https://m.weibo.cn/comments/hotflow`（`max_id` / `max_id_type` 分页）
- 发表评论：`POST https://m.weibo.cn/api/comments/create`
- 转发列表：`https://m.weibo.cn/api/statuses/repostTimeline`
- 发表转发：`POST https://m.weibo.cn/api/statuses/repost`
- 关注用户：`POST https://m.weibo.cn/api/friendships/create`
- 取消关注：`POST https://m.weibo.cn/api/friendships/destory`（微博历史拼写，兼容 `destroy`）
- 我的关注列表：`https://m.weibo.cn/api/container/getIndex?containerid=231051_-_followers_-_{uid}`
- 粉丝列表：`https://m.weibo.cn/api/container/getIndex?containerid=231051_-_fans_-_{uid}`
- 长微博全文：`https://m.weibo.cn/statuses/extend?id={statusId}`（读取 `data.longTextContent`）
- 图片上传：`POST https://m.weibo.cn/api/statuses/uploadPic`（multipart，文件字段 `pic`，读取 `pic_id`）
- 发布图文：`POST https://m.weibo.cn/api/statuses/update`（`content`、`visible`、`picId`）
- 读取可编辑微博：`GET https://m.weibo.cn/statuses/show?id={statusId}`（读取 `data.can_edit`、`data.raw_text`、`data.pic_ids`）
- 编辑正文：`POST https://m.weibo.cn/api/statuses/update`（`editId`、`content`，有配图时回传原 `picId`）
- 删除微博：`POST https://m.weibo.cn/profile/delMyblog`（`mid`）
- 视频上传：`POST https://weibo.com/ajax/multimedia/dispatch` 获取 `init_url` / `upload_url` / `check_url`，分片以 `application/octet-stream` 写入，校验 `action=finish`
- 发布视频：`POST https://weibo.com/ajax/statuses/update`（`content`、`pic_id`、`visible`、`media` JSON）
- 用户主页：`https://m.weibo.cn/api/container/getIndex?type=uid&value={uid}&containerid=107603{uid}&page={page}`（读取 `userInfo.following` 与 `userInfo.follow_me` 判断关注和互相关注）
- 移动端热搜：`https://m.weibo.cn/api/container/getIndex?containerid=...`
- 桌面端热搜兜底：`https://weibo.com/ajax/side/hotSearch`
- 原生搜索结果：`https://m.weibo.cn/api/container/getIndex?containerid=100103type%3D1%26q%3D{keyword}&page_type=searchall&page={page}`
- 视频地址：读取 `page_info.media_info.playback_list[].play_info.url`，并兼容 `mp4_720p_mp4` / `mp4_hd_url` / `mp4_sd_url` / `stream_url_hd` / `stream_url`
- 原图：优先使用接口返回的 `large` / `largest` URL，缺失时按图片扩展名从 `https://wx1.sinaimg.cn/large/{pid}.{ext}` 推导；GIF 会保留 `.gif` 扩展名

评论、转发、关注、发布、编辑与删除使用 `/api/config` 返回的 `st` 作为表单令牌，并附带 `X-XSRF-TOKEN` 请求头；该令牌会随会话刷新，不写入磁盘。视频上传使用 `weibo.com` 的 `XSRF-TOKEN` Cookie 与网页版会话。

## 隐私与安全

- 登录在微博官方 WebView 页面完成，应用不读取、不保存账号密码。
- 会话 Cookie 经 Android Keystore AES-GCM 加密后仅存储在本机；应用未申请备份权限。
- 无统计 SDK、无广告 SDK、无第三方服务器，不上传任何账号或浏览数据。
- 登录完成后，时间线、热搜、搜索、微博详情、用户主页、粉丝和视频播放均在客户端原生界面中完成，不会跳转系统浏览器。
- 图片直接从新浪图片 CDN 下载，视频由微博视频 CDN 直接播放或下载；应用自身不代理或上传媒体内容。
- 卸载应用会一并删除本机会话。

## 已知限制

- 使用微博非公开/移动端接口，接口字段或风控策略变化可能导致功能失效。
- 已支持原创微博的图文与视频发布，以及自己微博的正文编辑与删除；不支持投票、话题标签选择、定时发布、修改图片/GIF、点赞、私信等写操作。
- 编辑仅支持原创且不含视频的微博正文；原有图片/GIF 保持原样，不能在编辑页新增、替换或删除图片。转发微博、含视频微博和超过 2000 字的正文暂不支持编辑。
- 编辑权限由微博返回的 `can_edit` 控制，可能受发布时长、账号权限、会员状态或风控策略影响；无法编辑时会给出提示。
- 编辑与删除已通过编译和接口字段对接，但当前构建环境没有 Android 真机，尚未完成真实账号的端到端写操作验证；如微博接口调整，请以实际返回为准。
- 删除微博不可恢复；删除和编辑是否成功取决于账号权限、微博风控与频率限制。
- 图片/GIF 与视频发布是否成功取决于账号权限、微博风控与频率限制；图片超过约 5MB 或尺寸异常时，微博图床可能拒绝并返回错误，应用不会静默压缩原图。
- 评论/转发/关注是否成功取决于账号权限、博主设置、微博风控与频率限制。
- 视频上传依赖 `weibo.com` 网页版 Cookie；若登录页只同步了移动端会话，视频发布会提示重新登录。视频上传完成后微博仍需云端转码，刚发布时播放可能短暂转码中。
- 视频地址由微博 CDN 提供，可能受签名有效期、地区、账号权限或版权限制影响；播放器会自动尝试下一档清晰度，全部失败时会显示错误提示。
- 不同清晰度由微博接口返回，部分视频只提供单一清晰度，此时播放器不显示分辨率选择入口。
- 微博返回 HLS（`.m3u8`）清晰度时只支持在线播放，不能直接保存为本地 MP4；可在下载面板选择其他 MP4 档位。
- 部分微博视频使用设备不支持的编码（如部分 HEVC/HDR 档位），此时会自动回退到其他清晰度。
- 热搜分类在移动接口失败时会回退到公开热搜榜，此时分类可能不准确。
- 原生搜索结果依赖微博搜索接口，接口风控或账号搜索权限变化时可能返回空结果或错误。
- 用户主页微博是否可见取决于账号隐私设置和微博接口权限。
- 「我的」页面的关注/粉丝计数来自 `/api/config` 与用户资料接口；若网络或接口暂时不可用，会继续显示本机上次保存的数量。
- 大图查看器支持左右滑动浏览、单击图片返回正文，不支持双指自由缩放。
- 未在真机上做完整的登录/分页回归；首次使用如遇接口异常，请先确认微博网页端可正常访问。
- debug APK 体积较大（约 22 MB），release 构建可进一步裁剪。
